# What a Mess!

<img width="800" height="244" alt="what-a-mess-banner" src="https://github.com/user-attachments/assets/c16efb14-a723-4dee-a986-dc5711440613" />

A game about organizing rooms before it's too late!

Game developed in Godot v4.4.1 and made in 96 hours for the **GMTK 2026 Game Jam**, the theme was **Count Down**.

<img width="320" alt="GMTK Game Jam 2026 full logo" src="https://github.com/user-attachments/assets/9a9c9bf6-54ba-4ec9-bfa6-386bdb3e84d7" />

# Features

- Three fun levels to play: **bedroom**, **laboratory** and **kitchen**!
- Beat your score by improving your organization and timing.
- Epic cutscene before starting a level. Wow!
- There's a cat in the kitchen level.
- ~~Totally chill and not at all stressful gameplay...~~
- Jazz, a lot of jazz!

# Where can I play it?

The game can be played on the browser [here on itch.io](https://edoan.itch.io/what-a-mess)

But also you can download a windows version [here on the releases page](https://github.com/EdoanR/what-a-mess/releases)
